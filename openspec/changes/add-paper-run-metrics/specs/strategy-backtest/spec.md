## ADDED Requirements

### Requirement: 回测运行记录模拟画像

每一次回测运行 SHALL 在创建时记录模拟画像 `simulation_profile`：成本模型（启用状态与参数；未启用时记为「零成本」而非省略）、整手规则、交收规则、行情口径。该画像与纸面运行同名同形，是跨运行比较的共同口径。运行创建后配置变化 MUST NOT 改写已记录的画像。

#### Scenario: 零成本被记为已建模

- **WHEN** 一次回测未传 `cost_model`
- **THEN** 画像的成本维度记为「零成本（已建模）」，而不是缺失

#### Scenario: 画像随运行固定

- **WHEN** 一次回测以显式成本模型创建，之后部署默认值改变
- **THEN** 该运行读回的画像仍是创建时的参数
