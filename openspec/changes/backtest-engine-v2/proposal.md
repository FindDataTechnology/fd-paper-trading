## Why

现有回测器（`strategy/backtester.py`，2026-08 上线）是一段诚实的极简实现：日线 fill-at-close、6 个统计量、把"未成交的 LIMIT 不跨 bar 结转"写在 spec 里。但要让它承载"很多交易模式互相比较"这件事，它缺三样东西——每一样都对应一个已被上游项目验证的必要件：

- **无未来函数护栏**：FinRL-X 把 `validate_no_lookahead` 当作断言级设施（`walk_forward.py:478` 对决策日之后的数据直接抛错），而我们今天只能靠人工谨慎；
- **无 walk-forward 与基准对比**：单窗回测无法回答"这是策略还是运气"；FinRL-X 的 `WalkForwardAnalyzer` 与我们的 spec 都没有这个能力的对位；当前 6 个统计量里也没有任何基准相对指标；
- **无成本模型**：现状零成本，任何换手稍高的策略都会在纸面上发光——这是路线图批 3 交易模式 pack 上线前的必须项。

本变更是 quant-packs 路线图批 1.2，是 P1 策略工坊与 P2 自适应轮动的前置，同时为批 1.1 计算面（组合统计、walk-forward 切分）提供消费者。

## What Changes

- **walk-forward 回测模式**：新增回测运行模式，按"训练窗/测试窗/步长"切分并逐窗执行（窗口切分与无未来函数断言消费 fd-quant 计算面工具，不在本仓重实现）；输出逐窗统计与拼接后的整体曲线。现有单窗回测模式**保持不变**（既有 API 与结果形状不破坏）。
- **无未来函数断言**：回测在数据装载与每窗执行前调用验证器（`as_of` = 窗末/当前 bar 日期）；越界即失败并指名越界日期。可注入的泄漏夹具被断言抓住（验收项）。
- **成本模型**：可配的佣金（默认 0.025%，双边）、印花税（默认 0.05%，卖出单边）、滑点（默认 5bps，双边）；`cost_model.enabled=false` 时为零成本（与现状一致，向后兼容）。成本在成交价上体现（买入加滑点、卖出减滑点），税费从现金扣除。
- **统计扩展**：在既有 6 个统计量之上新增 `annual_return`（CAGR）、`annual_volatility`、`sortino`、`calmar`、`turnover`（年化换手）；计算原子复用 fd-quant 计算面（同一收益定义，跨仓对拍）。
- **基准对比**：回测请求可带一个或多个基准符号（默认 `000300.SS` 沪深300 / `000905.SS` 中证500 当可用，可显式覆盖）；输出基准的同期收益曲线与统计及相对指标（超额收益、跟踪误差、信息比）；基准数据不可用时**明确报缺**而非静默省略。
- **参数扫描**：对模板类策略提供参数网格扫描（笛卡尔积，上限约束防爆炸），输出每组参数的统计矩阵（按目标指标排序），并标注最佳组**仅为样本内**（不假装那是推荐）。
- **结果形状与 API 扩展**：`strategy_runs.stats` 增加上述字段；walk-forward 与扫描结果以新端点/字段暴露；既有 `POST /api/v1/strategies/{id}/backtests` 请求形状向后兼容（新增字段全部可选）。

## Capabilities

### New Capabilities

- `strategy-walkforward`: walk-forward 回测（窗口切分、逐窗执行、拼接曲线、逐窗统计）、参数扫描（网格、上限、排序、样本内标注）、基准对比（多基准、相对指标、缺数据报错）。

### Modified Capabilities

- `strategy-backtest`: 统计扩展（CAGR/年化波动/Sortino/Calmar/换手）；成本模型（佣金/印花税/滑点，可关）；无未来函数断言（装载与逐窗前置检查，越界失败）；回测请求接受可选基准与成本参数。

## Impact

- **仓**：`fd-paper-trading`（`src/fd_paper_trading/strategy/backtester.py`、运行模型与 API、web 回测面板）。
- **数据**：`strategy_runs` 增加字段（walk-forward 窗列表、扫描参数、成本配置快照）；`strategy_equity_points` 复用存拼接曲线。Alembic 迁移。
- **依赖**：fd-quant 计算面（`openspec/changes/fd-quant-compute-plane` 的组合统计与 walk-forward 工具）——通过 MCP 或库调用，实施时按"同仓依赖优先"定（回测在服务内、计算面是外部服务，走 MCP HTTP）；若批 1.1 未就绪，本变更先以内部实现垫底并在 tasks 标注对拍要求（**不通过则不宣称完成**）。
- **基准数据**：走既有市场数据提供方（fd-open-data / 通道 B 供数）；基准符号不可用时明确报缺。
- **向后兼容**：既有单窗回测的请求与统计字段语义不变；新增字段可选、默认关闭成本模型与基准（保持零成本零基准的现状输出）。
- **不做**：不做 tick/盘口模拟、不做做空与杠杆（持仓方向假设不变）、不做多标的组合回测（属批 3.1 权重模式回测，在 pack-strategy-lab 内承载）。
